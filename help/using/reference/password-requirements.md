# Exigences en matière de mot de passe, comptes verrouillés et mots de passe oubliés{#password-requirements-locked-accounts-and-forgotten-passwords}

Audience Manager peut être configuré de manière à ce que les mots de passe expirent tous les 30 jours. Si vous souhaitez activer l’expiration du mot de passe, adressez-vous à votre conseiller Audience Manager ou à l’assistance clientèle. Consultez cette section pour connaître les exigences en matière de mot de passe et la procédure à suivre pour récupérer un mot de passe perdu ou oublié.

**Exigences en matière de mot de passe**

Pour être valide, votre mot de passe [!DNL Audience Manager] doit répondre aux exigences suivantes :

| Exigences | Description |
|---|---|
| des variables | Les mots de passe peuvent contenir entre 12 et 40 caractères. |
| Contenu | Les mots de passe doivent :<ul><li>commencer et se terminer par un caractère alphanumérique ;</li><li>Contiennent au moins une lettre majuscule et une lettre minuscule.</li><li>Contiennent au moins un chiffre.</li><li>Contiennent au moins un caractère spécial (deux-points exclus).</li><li>comprendre uniquement des lettres de l’alphabet latin.</li></ul> |
| Versions | Les mots de passe doivent être différents des 12 mots de passe précédents. |
| Éléments interdits | Les mots de passe ne doivent pas contenir :<ul><li>Votre prénom ou votre nom.</li><li>Votre adresse e-mail ou votre identifiant utilisateur [!DNL Adobe].</li><li>Lettres ou chiffres consécutifs.</li><li>Lettres ou nombres séquentiels.</li><li>Mots de passe couramment utilisés.</li></ul> |

Pour plus d’informations sur la réinitialisation de votre mot de passe, consultez [Modifier les paramètres du compte](../features/administration/edit-account-settings.md).

**Verrouillage du compte**

Pour des raisons de sécurité, [!DNL Audience Manager] limite temporairement les tentatives de connexion ayant échoué. Si vous dépassez la limite, [!DNL Audience Manager] bloque les autres tentatives de connexion pendant une courte période, puis les autorise automatiquement à nouveau. Il n’est pas nécessaire de contacter un administrateur ou un représentant des services partenaires pour déverrouiller votre compte.

**Mot de passe perdu/oublié**

Sélectionnez **[!UICONTROL Forgot password]** sur la page de connexion pour réinitialiser votre mot de passe. [!DNL Audience Manager] vous envoie un e-mail contenant un lien pour réinitialiser votre mot de passe. Sélectionnez le lien, puis créez un mot de passe conforme aux exigences de mot de passe. Le lien fonctionne une seule fois.

**Configuration du nouveau compte**

Lorsqu’un administrateur crée votre compte, [!DNL Audience Manager] vous envoie un e-mail contenant un lien pour définir votre mot de passe. Sélectionnez le lien, puis créez un mot de passe conforme aux exigences de mot de passe. Vous devez définir votre mot de passe avant de pouvoir vous connecter pour la première fois.
